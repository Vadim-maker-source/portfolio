# Prototype flow

- Навигация ведёт к разделам `#about`, `#experience`, `#technologies`, `#contact`.
- Главный CTA ведёт к фактическому опыту.
- Курсор меняет перспективу WebGL-консоли.
- Hover или фокус на кнопке направления поднимает соответствующий 3D-модуль.
- Скролл внутри sticky-stage разбирает консоль и собирает её снова.
- Второй CTA и финальная контактная строка открывают Telegram.
- GitHub открывает репозитории автора.
- Ячейки инструментов меняют состояние только цветом, без подъёма и масштабирования.
- Scroll reveal ограничен коротким fade + 14px translate и отключается при reduced-motion.
