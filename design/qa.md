# Design QA

## Проверено

- Desktop hero: заголовок, описание и CTA формируют ясную двухколоночную иерархию.
- 3D identity: это реальная WebGL-сцена; знак V67 связан с именем автора, символы расходятся по скроллу и реагируют на курсор.
- Experience: семь направлений читаются как строки спецификации без карточного шума.
- Technologies: названия и категории читаемы; сетка сохраняет промышленную логику.
- Journey: отдельная тёмная секция создаёт смену ритма без glow и декора.
- Contact: Telegram и GitHub доступны как крупные прямые ссылки.
- Accessibility: семантические секции, heading hierarchy, skip-link, focus-visible, reduced-motion.
- `npm run lint` — pass.
- `npm run build` — pass.

## Anti-AI pass

- Нет градиентов, свечений, glassmorphism, pill-бейджей, rounded cards, декоративных метрик или псевдотерминалов в публичной странице.
- Визуальная глубина есть только у предметного 3D-изображения.
- Фиолетовый используется как точка, физический слайдер и hover/focus сигнал.
